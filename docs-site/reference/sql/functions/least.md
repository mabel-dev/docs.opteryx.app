# LEAST

Determines the minimum element in an array column.

**Category:** Array Functions

## Syntax

```
LEAST(arr)
```

## Arguments

- **arr** `array`
    Input array or vector value.

## Returns

**element type of `arr`** — Returns a single element from `arr`, preserving the array's element type.
