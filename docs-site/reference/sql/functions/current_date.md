# CURRENT_DATE

Current date.

**Category:** Date & Time Functions

## Syntax

```sql
CURRENT_DATE
```

## Returns

**DATE** — Returns the computed result as `DATE`.

## Usage Notes

Canonical SQL-92 form is `CURRENT_DATE`. Opteryx also accepts `CURRENT_DATE()`.
