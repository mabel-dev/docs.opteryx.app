# LENGTH

Computes length of string or number of elements in an array.

**Category:** String Functions

## Syntax

```sql
LENGTH(string)
```

```sql
LENGTH(arr)
```

## Arguments

- **string** `varchar`
    String input value.
- **arr** `array`
    Input array or vector value.

## Returns

**INTEGER** — Returns the computed result as `INTEGER`.
