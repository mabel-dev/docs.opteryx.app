# LEFT

Extract leftmost characters.

**Category:** String Functions

## Syntax

```sql
LEFT(string, length)
```

## Arguments

- **string** `varchar`
    String input value.
- **length** `integer`
    Integer input value.

## Returns

**VARCHAR** — Returns the computed result as `VARCHAR`.
