# LEFT

Computes leftmost n characters.

**Category:** String Functions

## Syntax

```
LEFT(str, n)
```

## Arguments

- **str: varchar** — Input string value.
- **n: integer** — Integer control value used by the function.

## Returns

**varchar** — Returns the computed result as `varchar`.
