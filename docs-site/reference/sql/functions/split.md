# SPLIT

Split string into array.

**Category:** String Functions

## Syntax

```
SPLIT(str, [delimiter], [limit])
```

## Arguments

- **str**: Input string value.
- **delimiter**: Separator used to split the input string. Optional.
- **limit**: Maximum number of items or splits to return. Optional.

## Returns

Returns the computed result as `array`.
