# ABS

Calculates the absolute value of the input number.

**Category:** Numeric Functions

## Syntax

```
ABS(num)
```

## Arguments

- **num** `number`
    Numeric input value.

## Returns

**same as `num`** — Returns a value with the same type as `num`.
