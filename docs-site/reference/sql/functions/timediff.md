# TIMEDIFF

Difference between two times.

**Category:** Date & Time Functions

## Syntax

```sql
TIMEDIFF(time1, time2)
```

## Arguments

- **time1** `temporal`
    First date, time, or timestamp value.
- **time2** `temporal`
    Second date, time, or timestamp value.

## Returns

**INTEGER** — Returns the computed result as `INTEGER`.
