# TIMEDIFF

Difference between two times.

**Category:** Date & Time Functions

## Syntax

```
TIMEDIFF(time1, time2)
```

## Arguments

- **time1**: First date, time, or timestamp value.
- **time2**: Second date, time, or timestamp value.

## Returns

Returns the computed result as `integer`.
