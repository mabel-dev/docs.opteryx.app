# LEVENSHTEIN

Levenshtein edit distance between two strings.

**Category:** String Functions

## Syntax

```
LEVENSHTEIN(a, b)
```

## Arguments

- **a: varchar** — First input value.
- **b: varchar** — Second input value.

## Returns

**integer** — Returns the computed result as `integer`.
