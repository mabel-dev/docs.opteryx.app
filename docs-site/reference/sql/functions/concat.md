# CONCAT

Concatenates all input strings.

**Category:** String Functions

## Syntax

```
CONCAT(str1, [more...])
```

## Arguments

- **str1**: First input string value.
- **more**: Additional input values. Optional. Can be repeated.

## Returns

Returns the computed result as `varchar`.
