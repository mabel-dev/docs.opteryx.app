# CONCAT

Concatenates all input strings.

**Category:** String Functions

## Syntax

```
CONCAT(str1, [more...])
```

## Arguments

- **str1: varchar** — First input string value.
- **more: varchar** — Additional input values. Optional. Can be repeated.

## Returns

**varchar** — Returns the computed result as `varchar`.
