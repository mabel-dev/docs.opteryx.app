# LOG

Logarithm with arbitrary base.

**Category:** Numeric Functions

## Syntax

```
LOG(num, base)
```

## Arguments

- **num: number** — Numeric input value.
- **base: number** — Numeric input value.

## Returns

**double** — Returns the computed result as `double`.
