# SORT

Sorts an array column.

**Category:** Array Functions

## Syntax

```sql
SORT(arr)
```

## Arguments

- **arr** `array`
    Input array or vector value.

## Returns

**same as `arr`** — Returns a sorted array while preserving the input array type.
