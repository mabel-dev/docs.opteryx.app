# SIGN

Computes -1 for negative, 0 for zero, 1 for positive.

**Category:** Numeric Functions

## Syntax

```sql
SIGN(num)
```

## Arguments

- **num** `number`
    Numeric input value.

## Returns

**INTEGER** — Returns the computed result as `INTEGER`.
