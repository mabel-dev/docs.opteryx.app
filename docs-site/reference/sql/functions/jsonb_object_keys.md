# JSONB_OBJECT_KEYS

Extract keys from JSON object.

**Category:** Struct/JSON Functions

## Syntax

```sql
JSONB_OBJECT_KEYS(json)
```

## Arguments

- **json** `any`
    JSON object or document value to inspect.

## Returns

**ARRAY<VARIANT>** — Returns the computed result as `ARRAY<VARIANT>`.
