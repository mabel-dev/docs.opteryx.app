# UNIXTIME

Convert TIMESTAMP to Unix epoch seconds.

**Category:** Date & Time Functions

## Syntax

```sql
UNIXTIME(date)
```

## Arguments

- **date** `temporal`
    Date, time, or timestamp value to evaluate.

## Returns

**INTEGER** — Returns the computed result as `INTEGER`.
