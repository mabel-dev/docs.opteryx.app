# TO_CHAR

Converts an integer codepoint to its corresponding character.

**Category:** String Functions

## Syntax

```
TO_CHAR(num)
```

## Arguments

- **num** `integer`
    Numeric input value.

## Returns

**varchar** — Returns the computed result as `varchar`.
