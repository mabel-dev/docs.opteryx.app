# CURRENT_TIME

Current time.

**Category:** Date & Time Functions

## Syntax

```
CURRENT_TIME
```

## Returns

**time** — Returns the computed result as `time`.

## Usage Notes

Canonical SQL-92 form is `CURRENT_TIME`. Opteryx also accepts `CURRENT_TIME()`.
