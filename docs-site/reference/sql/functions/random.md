# RANDOM

Computes uniform random float(s) in [0, 1).

**Category:** Utility Functions

## Syntax

```
RANDOM(n)
```

```
RANDOM()
```

## Arguments

- **n**: Number of random values to generate.

## Returns

Returns the computed result as `double`.
