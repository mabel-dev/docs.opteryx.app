# ARRAY_CONTAINS

Test if array contains item.

**Category:** Array Functions

## Syntax

```sql
ARRAY_CONTAINS(arr, item)
```

## Arguments

- **arr** `array`
    Input array or vector value.
- **item** `any`
    Must be of the array's element type.

## Returns

**BOOLEAN** — Returns the computed result as `BOOLEAN`.
