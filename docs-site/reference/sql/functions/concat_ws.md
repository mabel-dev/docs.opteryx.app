# CONCAT_WS

Concatenate with separator.

**Category:** String Functions

## Syntax

```
CONCAT_WS(sep, str1, [more...])
```

## Arguments

- **sep**: Separator inserted between each concatenated string.
- **str1**: First string value to concatenate.
- **more**: Additional string values to concatenate after `str1`. Optional. Can be repeated.

## Returns

Returns the computed result as `varchar`.
