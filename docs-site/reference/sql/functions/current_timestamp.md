# CURRENT_TIMESTAMP

Current timestamp.

**Category:** Date & Time Functions

## Syntax

```sql
CURRENT_TIMESTAMP
```

## Returns

**TIMESTAMP[US]** — Returns the computed result as `TIMESTAMP[US]`.

## Usage Notes

Canonical SQL-92 form is `CURRENT_TIMESTAMP`. Opteryx also accepts `CURRENT_TIMESTAMP()`.
