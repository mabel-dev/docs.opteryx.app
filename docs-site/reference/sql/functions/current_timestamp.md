# CURRENT_TIMESTAMP

Current timestamp.

**Category:** Date & Time Functions

## Syntax

```
CURRENT_TIMESTAMP
```

## Returns

**timestamp** — Returns the computed result as `timestamp`.

## Usage Notes

Canonical SQL-92 form is `CURRENT_TIMESTAMP`. Opteryx also accepts `CURRENT_TIMESTAMP()`.
