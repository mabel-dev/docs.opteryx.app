# RIGHT

Extract rightmost characters.

**Category:** String Functions

## Syntax

```sql
RIGHT(string, length)
```

## Arguments

- **string** `varchar`
    String input value.
- **length** `integer`
    Integer input value.

## Returns

**VARCHAR** — Returns the computed result as `VARCHAR`.
