# TRIM

Trim leading and trailing characters.

**Category:** String Functions

## Syntax

```
TRIM(str, [chars])
```

## Arguments

- **str**: Input string value.
- **chars**: Characters to remove from the input string. Optional.

## Returns

Returns the computed result as `varchar`.
