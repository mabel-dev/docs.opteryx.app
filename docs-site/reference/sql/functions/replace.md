# REPLACE

Replace all occurrences.

**Category:** String Functions

## Syntax

```
REPLACE(string, search, replace_val)
```

## Arguments

- **string** `varchar`
    String input value.
- **search** `varchar`
    Text or pattern to replace in the input.
- **replace_val** `varchar`
    String input value.

## Returns

**varchar** — Returns the computed result as `varchar`.
