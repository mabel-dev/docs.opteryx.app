# FROM_UNIXTIME

Convert Unix timestamp to TIMESTAMP.

**Category:** Date & Time Functions

## Syntax

```sql
FROM_UNIXTIME(ts)
```

## Arguments

- **ts** `number`
    Unix timestamp expressed in seconds.

## Returns

**TIMESTAMP[US]** — Returns the computed result as `TIMESTAMP[US]`.
