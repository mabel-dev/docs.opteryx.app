# FROM_UNIXTIME

Convert Unix timestamp to TIMESTAMP.

**Category:** Date & Time Functions

## Syntax

```
FROM_UNIXTIME(ts)
```

## Arguments

- **ts: number** — Unix timestamp expressed in seconds.

## Returns

**timestamp** — Returns the computed result as `timestamp`.
