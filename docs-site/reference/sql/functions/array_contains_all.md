# ARRAY_CONTAINS_ALL

Test if array contains all items from set.

**Category:** Array Functions

## Syntax

```sql
ARRAY_CONTAINS_ALL(arr, items)
```

## Arguments

- **arr** `array`
    Input array or vector value.
- **items** `array`
    Collection of values to compare against the array.

## Returns

**BOOLEAN** — Returns the computed result as `BOOLEAN`.
