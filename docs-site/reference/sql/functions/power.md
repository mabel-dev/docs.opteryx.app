# POWER

Raise base to exponent (SQL-92).

**Category:** Numeric Functions

## Syntax

```
POWER(num, exp)
```

## Arguments

- **num**: Numeric input value.
- **exp**: Exponent to raise the base value by.

## Returns

Returns the computed result as `double`.
