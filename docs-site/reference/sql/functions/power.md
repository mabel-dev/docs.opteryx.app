# POWER

Raise base to exponent (SQL-92).

**Category:** Numeric Functions

## Syntax

```
POWER(num, exp)
```

## Arguments

- **num: number** — Numeric input value.
- **exp: number** — Exponent to raise the base value by.

## Returns

**double** — Returns the computed result as `double`.
