# OCTET_LENGTH

Computes the number of bytes in a string, regardless of string type.

**Category:** String Functions

## Syntax

```sql
OCTET_LENGTH(string)
```

## Arguments

- **string** `varchar`
    String input value.

## Returns

**INTEGER** — Returns the computed result as `INTEGER`.
