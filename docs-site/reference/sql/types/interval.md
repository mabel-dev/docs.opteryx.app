# INTERVAL

Duration or period of time.

## Example

```
INTERVAL '1' DAY
```

## Notes

Sub-month components are stored as microseconds.

**Family:** interval

## Flags

- **numeric**: `False`
- **temporal**: `True`
- **collection**: `False`
- **parameterized**: `False`
