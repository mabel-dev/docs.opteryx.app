# ARRAY

Ordered sequence of elements of a single type.

## Example

```
ARRAY[1, 2, 3]
```

**Family:** nested

## Flags

- **numeric**: `False`
- **temporal**: `False`
- **collection**: `True`
- **parameterized**: `True`

## Parameterized Forms

- `ARRAY<type>`
