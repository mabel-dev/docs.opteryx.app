# FLOAT

64-bit IEEE 754 double-precision floating-point number.

## Example

```
3.14
```

## Range

- **Min:** `-1.7976931348623157e+308`
- **Max:** `1.7976931348623157e+308`

## Notes

NaN sorts highest; -0.0 and 0.0 are treated as equal.

**Family:** numeric

## Flags

- **numeric**: `True`
- **temporal**: `False`
- **collection**: `False`
- **parameterized**: `False`
