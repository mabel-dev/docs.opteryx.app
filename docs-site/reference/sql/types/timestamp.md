# TIMESTAMP

Date and time with microsecond precision.

## Example

```
TIMESTAMP '2024-01-01 12:00:00'
```

## Notes

Stored as microseconds since the Unix epoch.

**Family:** temporal

## Flags

- **numeric**: `False`
- **temporal**: `True`
- **collection**: `False`
- **parameterized**: `False`
