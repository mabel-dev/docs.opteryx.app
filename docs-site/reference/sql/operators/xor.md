# XOR

**Category:** logical

**Token:** `XOR`

**Signatures:** 1

## Signatures

- `boolean XOR boolean` → boolean

## Types

- **Left:** boolean
- **Right:** boolean
- **Result:** boolean

## Notes

Returns `TRUE` when exactly one operand is `TRUE`. Returns `FALSE` when both operands are the same value. Returns `NULL` when either operand is `NULL`.
