# VECTOR

Fixed-length numeric vector.

## Example

```
[0.1, 0.2, 0.3]
```

## Notes

Length can be specified as VECTOR[<size>].

**Canonical name:** VECTOR

**Accepted spellings:** vector

**Family:** vector

## Flags

- **numeric**: `False`
- **temporal**: `False`
- **collection**: `True`
- **parameterized**: `False`
