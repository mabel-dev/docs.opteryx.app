# NVARCHAR

UTF-8 encoded text string.

## Example

```
'héllo'
```

## Notes

Stores arbitrary Unicode content. JSON/JSONB data is stored as NVARCHAR.

**Family:** text

## Flags

- **numeric**: `False`
- **temporal**: `False`
- **collection**: `True`
- **parameterized**: `False`
