# INTEGER

Signed 64-bit integer.

## Example

```
42
```

## Range

- **Min:** `-9223372036854775808`
- **Max:** `9223372036854775807`

## Notes

Parsed from strings, floats, and booleans.

**Family:** numeric

## Flags

- **numeric**: `True`
- **temporal**: `False`
- **collection**: `False`
- **parameterized**: `False`
