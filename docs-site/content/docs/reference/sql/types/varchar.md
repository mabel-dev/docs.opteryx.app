# VARCHAR

Variable-length string.

## Example

```
hello
```

## Range

- **Min:** `0`

## Notes

By default, length is unbounded unless specified (e.g. VARCHAR[255]).

**Family:** text

## Flags

- **numeric**: `False`
- **temporal**: `False`
- **collection**: `False`
- **parameterized**: `False`
