# BOOLEAN

Boolean value representing true or false.

## Example

```
TRUE
```

## Range

- **Min:** `False`
- **Max:** `True`

## Notes

Accepted values include TRUE/FALSE, 1/0, YES/NO, ON/OFF (case-insensitive).

**Family:** boolean

## Flags

- **numeric**: `False`
- **temporal**: `False`
- **collection**: `False`
- **parameterized**: `False`
