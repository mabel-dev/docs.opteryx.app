# TIME

Time of day (HH:MM:SS).

## Example

```
12:34:56
```

## Range

- **Min:** `00:00:00`
- **Max:** `23:59:59.999999`

## Notes

Parsed from ISO time strings.

**Family:** temporal

## Flags

- **numeric**: `False`
- **temporal**: `True`
- **collection**: `False`
- **parameterized**: `False`
