# DOUBLE

Double-precision floating point number.

## Example

```
123.45
```

## Range

- **Min:** `-1.7976931348623157e+308`
- **Max:** `1.7976931348623157e+308`

## Notes

Supports scientific notation (e.g. 1.23e5).

**Family:** numeric

## Flags

- **numeric**: `True`
- **temporal**: `False`
- **collection**: `False`
- **parameterized**: `False`
