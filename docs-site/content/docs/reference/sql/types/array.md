# ARRAY

Array of values of a single type.

## Example

```
[1, 2, 3]
```

## Notes

Element type is specified as ARRAY<INTEGER>, ARRAY<VARCHAR>, etc.

**Family:** nested

## Flags

- **numeric**: `False`
- **temporal**: `False`
- **collection**: `True`
- **parameterized**: `True`

## Parameterized Forms

- `ARRAY<INTEGER>`
