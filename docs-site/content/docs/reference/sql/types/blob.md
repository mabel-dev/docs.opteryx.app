# BLOB

Binary large object (bytes).

## Example

```
b'\x01\x02'
```

## Range

- **Min:** `0`

## Notes

By default, length is unbounded unless specified (e.g. BLOB[1024]).

**Family:** binary

## Flags

- **numeric**: `False`
- **temporal**: `False`
- **collection**: `False`
- **parameterized**: `False`
