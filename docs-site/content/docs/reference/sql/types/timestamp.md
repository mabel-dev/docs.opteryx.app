# TIMESTAMP

Timestamp including date and time.

## Example

```
2023-04-18T12:34:56
```

## Range

- **Min:** `0001-01-01 00:00:00`
- **Max:** `9999-12-31 23:59:59.999999`

## Notes

Parsed from ISO 8601 strings and unix timestamps.

**Family:** temporal

## Flags

- **numeric**: `False`
- **temporal**: `True`
- **collection**: `False`
- **parameterized**: `False`
