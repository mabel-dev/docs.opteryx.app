# SIGN

Computes -1 for negative, 0 for zero, 1 for positive.

**Category:** Numeric Functions

## Syntax

```
SIGN(num)
```

## Arguments

- **num** `number`
    Numeric input value.

## Returns

**int64** — Returns the computed result as `int64`.
