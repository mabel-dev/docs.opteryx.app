# TO_ASCII

Converts the first character of a string to its integer codepoint.

**Category:** String Functions

## Syntax

```
TO_ASCII(string)
```

## Arguments

- **string** `varchar`
    String input value.

## Returns

**int64** — Returns the computed result as `int64`.
