# LOG

Logarithm with arbitrary base.

**Category:** Numeric Functions

## Syntax

```
LOG(num, base)
```

## Arguments

- **num** `number`
    Numeric input value.
- **base** `number`
    Numeric input value.

## Returns

**float64** — Returns the computed result as `float64`.
