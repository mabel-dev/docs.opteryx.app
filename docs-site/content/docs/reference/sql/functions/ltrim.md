# LTRIM

Trim leading characters.

**Category:** String Functions

## Syntax

```
LTRIM(str, [chars])
```

## Arguments

- **str** `varchar`
    Input string value.
- **chars** `varchar` [optional]
    Characters to remove from the input string. Optional.

## Returns

**varchar** — Returns the computed result as `varchar`.
