# Integer division

Integer division operator.

Divides two integers and truncates the result toward zero.

**Category:** binary

**SQL symbol:** `DIV`

## Example

```sql
SELECT 1 DIV 1;
```

## Signatures

- `integer DIV integer` → integer

## Types

- **Left:** integer
- **Right:** integer
- **Result:** integer
