# Bitwise XOR

Bitwise XOR operator.

Combines integer operands using a bitwise exclusive OR operation.

**Category:** binary

**Node kind:** binary

**SQL symbol:** `^`

## Example

```sql
SELECT col1 ^ col2 FROM table;
```

**Signatures:** 1
