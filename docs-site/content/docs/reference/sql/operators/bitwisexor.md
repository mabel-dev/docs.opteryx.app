# Bitwise XOR

Bitwise XOR operator.

Combines integer operands using a bitwise exclusive OR operation.

**Category:** binary

**SQL symbol:** `^`

## Example

```sql
SELECT 1 ^ 1;
```

## Signatures

- `integer ^ integer` → integer

## Types

- **Left:** integer
- **Right:** integer
- **Result:** integer
