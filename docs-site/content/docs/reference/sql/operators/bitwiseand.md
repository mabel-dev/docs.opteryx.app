# Bitwise AND

Bitwise AND operator.

Combines integer operands using a bitwise AND operation.

**Category:** binary

**Node kind:** binary

**SQL symbol:** `&`

## Example

```sql
SELECT col1 & col2 FROM table;
```

**Signatures:** 1

## Signatures

- `integer & integer` → integer

## Types

- **Left:** integer
- **Right:** integer
- **Result:** integer
