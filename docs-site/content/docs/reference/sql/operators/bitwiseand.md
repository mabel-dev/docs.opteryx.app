# Bitwise AND

Bitwise AND operator.

Combines integer operands using a bitwise AND operation.

**Category:** bitwise

**SQL symbol:** `&`

## Example

```sql
SELECT 1 & 1;
```

## Signatures

- `integer & integer` → integer

## Types

- **Left:** integer
- **Right:** integer
- **Result:** integer
