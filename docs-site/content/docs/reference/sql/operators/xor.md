# Logical XOR

Logical exclusive OR.

Returns true when exactly one boolean operand evaluates to true.

**Category:** logical

**SQL symbol:** `XOR`

## Example

```sql
SELECT TRUE XOR TRUE;
```

## Signatures

- `boolean XOR boolean` → boolean

## Types

- **Left:** boolean
- **Right:** boolean
- **Result:** boolean
