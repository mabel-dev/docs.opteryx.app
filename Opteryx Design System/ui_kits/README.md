# Opteryx UI Kits

Two product recreations, each a self-contained click-thru.

- **studio/** — the Opteryx Studio SQL IDE. Header with natural-language "Ask" bar, left sidebar (Datasets + Recent Queries), SQL editor, tabbed Results / Details / Execution Plan, SQL Reference drawer. Open `studio/index.html`.
- **marketing/** — the opteryx.app landing page. Hero, three-pillar feature row, BI integrations, CTA strip, footer. Open `marketing/index.html`.

Every component reads tokens from `../../colors_and_type.css` and uses icons from `../../assets/icons/`.
